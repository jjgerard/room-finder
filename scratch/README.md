# scratch

Helpers that are not part of the timetable build.

- `lab-capacities.js` — paste into the browser console on Ulster's Resource
  Booker (signed in, after typing in the resource search box) to read the
  recorded capacity of Belfast's computing labs. It copies the headers the
  app already set and never reads the token. The capacities it produced are
  committed in `timetable/data/room_capacities.csv`.
