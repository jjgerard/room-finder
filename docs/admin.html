Reading what the site currently holds…

1 Sign in to Resource Booker

This page cannot sign you in or read the timetable itself. The API wants a token that Microsoft issues inside the booking app, and a page on this domain has no way to get one — so the reading happens in a tab you are already signed in to, and comes back here as a file.

The address is kept in this browser so you only type it once.

2 Read the term

One command does all of this. node tools/fetch-term.mjs --term autumn opens a real browser, waits while you sign in, reads the term and writes the file. The first run asks for the booking-type address; after that the signed-in profile is kept in .auth/ and it needs no attention at all. Use it in preference to the console — the console can only capture the app's headers from requests made after you paste, and by then the app has usually made the ones it makes on load, which is why a paste often sits there doing nothing. The runner installs the capture before the page's own code, so there is no window to miss.

What follows is the same reader by hand, for when node is not to hand.

  1. In the Resource Booker tab, do one thing in the page first — type in the room search box, or click the calendar's next arrow. The script borrows the headers the app itself sends, and cannot see them until the app has sent something.
  2. Open the console (F12 → Console). Some browsers make you type allow pasting once before they will accept a paste.
  3. Paste, press Enter. It reads about 550 rooms four at a time and downloads snapshot-autumn.json. Two or three minutes.

4 Write it, in the repo

This page cannot write to the repository. When the comparison above looks right, run these where you have the code checked out.

This refreshes the timetables as they stand, not the rebuild. The clash graph — which classes share students — was inferred from the timetable as it was, and the API carries no enrolment data, so it stays as it is. The rebuilt terms are solutions to the old timetable too: if much has moved, re-solve them (node timetable/solve.js --term autumn --seeds 30 --clashes evidenced --out docs/data) rather than leaving them claiming to be a repair of something that has changed.
